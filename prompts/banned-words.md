# 分级禁用表达

## 用途

按风险等级查询并替换模板化表达。不是一份「坏词大全」，而是判断顺序：
先看是否真属套路，再看密度与语境，最后决定删、改还是留。
词表只约束表达，不改变剧情事实；功能性写法可以保留并登记。

## 硬规则

先定级，再决定删、改或留：

1. **硬禁**：真人语料里几乎不出现、模型特有的表达，命中即改。不能只换同义词，要落回具体动作、物件、台词或后果。
2. **慎用**：真人也会用，但高频出现会形成模板腔。按密度、语境与是否偷懒判断；孤立、自然的使用可以保留。
3. **看文体**：在特定题材或载体里可能是正常写法，例如古风正式用语、系统公告、公文条文、角色口语。先判断文体与说话人，再决定去留。

## 硬禁

| 词 / 句式 | 替代方向 | 何时可保留 |
|---|---|---|
| 眼中闪过一丝 X | 写他说了什么、做了什么，或直接删 | 对方明确读到了这个眼神并据此行动 |
| 嘴角勾起一抹 X | 他笑了、他撇嘴、他别开脸 | 需要精确表情且有上下文对照 |
| 心中涌起一股 X | 写它改变了哪个选择、哪句台词、哪件东西 | 情绪直接推动下一步且无动作可承载 |
| 不由得 / 不由自主 | 直接写动作 | 角色确实失去身体控制并造成后果 |
| 不禁 | 直接写动作 | 极少；通常删 |
| 深吸一口气 | 把话咽回去、先不接、转身去做别的事 | 正在为高风险动作做生理准备 |
| 指尖 / 指节泛白 | 删，或写手正在用力的具体后果 | 有伤势、动作失败或明确情节后果 |
| 瞳孔一缩 / 瞳孔微缩 | 写他看到的那个东西，或写下一步动作 | 角色确实因强光、疼痛或震惊产生生理反应 |
| 目光如炬 / 眼神锐利 | 写对方因此做了什么反应 | 角色本人有明确判断且据此行动 |
| 不容置疑 / 显而易见 / 毫无疑问 | 直接说事实，或写证据 | 角色在对话中刻意下判断 |
| 前所未有 | 给出对比参照 | 有可验证的对照且信息必要 |
| 此时此刻 / 只见 | 删，直接给画面 | 场内公告、屏幕、字幕原文 |
| 终于明白 / 从这一刻开始 | 写未完成的动作、具体缺口或下一步 | 角色判断带偏见且改变行动 |
| 命运齿轮 / 命运獠牙 / 早已布好的棋局 | 落到角色当下可见的文件、动作、对话或物理后果 | 角色本人相信宿命，且这是他的偏见 |
| 属于他的反击才刚刚开始 | 用一个具体行动或未解决问题收尾 | 角色亲口说出且符合声线 |
| 她不知道的是 / 殊不知 / 多年以后 | 删，只写角色此刻知道的 | 有明确全知叙述框架且作者已授权 |
| 取而代之的是 | 直接写新状态 | 极少；通常删 |
| 散发着 X 气息 / 气场 | 写旁人的反应或具体行为 | 角色本人嗅到、感到且有后续影响 |
| 显得（有些）X | 写动作或台词 | 旁观角色的主观判断且带偏见 |
| 声音不大，却带着 X | 写台词内容或声音特征 | 对方据此改变判断 |
| 宛如 / 宛若 / 犹如（成片） | 白描，或只留一个生活化比喻 | 比喻贴角色视角且传递新信息 |

## 慎用

| 词 / 句式 | 替代方向 | 何时可保留 |
|---|---|---|
| 突然 / 陡然 / 骤然 / 猛然 | 用具体动作或事件顺序表现突发 | 真实突发、时间压缩、角色口语 |
| 猛地 / 瞬间 | 写动作结果 | 峰值重拍，且不是每段都用 |
| 死死地 | 写具体抓握、盯视造成的后果 | 角色口语或确有身体对抗 |
| 似乎 / 好像 | 写不确定的来源或证据 | 视角人物确实无法判断 |
| 缓缓 / 微微 / 轻轻 / 淡淡 | 删，或换成具体动作 | 每千字合计不超过 3 个，且孤立即自然使用 |
| 很 / 非常 | 用具体程度或后果 | 日常叙述自然使用，不按零容忍处理 |
| 像 / 好像 / 仿佛 / 如同 | 保留最能传递信息的一两个比喻 | 生活化、角色化、单个有功能 |
| 于是乎 / 与此同时 / 从而 / 因而 / 诚然 | 删或改口语，用事件顺序承接 | 正式文体或角色刻意书面腔 |
| 一时间 / 半晌 / 片刻 | 写具体动作或时间锚点 | 古风、文言色彩叙述或角色口语 |

## 看文体

| 词 / 句式 | 替代方向 | 何时可保留 |
|---|---|---|
| 成语（不动声色、心不在焉等） | 对话与贴角色叙述少用，旁白可留 | 旁白自然使用，或角色身份需要 |
| 文言词（已然、未、须、不得） | 白话化：已经、还没、要、不能 | 历史题材、公文、系统公告、规则条文 |
| 专业术语 | 只留必要项，用白话补一句用途 | 行业内角色对话、硬核题材、设定载体 |
| 破折号 / 省略号停顿 | 改句号、逗号、短句、换行或动作 | 本书文风明确登记为功能性停顿 |
| 感叹号 / 问号 | 按语气保留，不压平成句号 | 质问、爆发峰值、真实疑问 |
| 方言 / 粗话 | 按人物身份与场合使用 | 角色真实会这样说，且服务人物与情绪 |

## 使用规则

1. **替换不复用**：同一禁用表达在一章内多次命中时，各处给不同的具体化写法。同一个替换词反复出现，会变成新的模板。
2. **先删抽象总结，再落地**：遇到成串套词，先删掉抽象总结与判断，再把情绪落到角色当下可见的动作、物件、对话与后果。
3. **套式反应逐处测试**：删掉这处身体或语气细节，信息、选择、关系或物理结果有损失吗？无损就删；不换部位、不换同义动作。
4. **密度服从语境**：弱化副词按每千字合计计数；比喻按成片程度判断，不按单个词判死刑。
5. **功能优先**：伏笔、钩子、人设、人物记忆、因果锚点、必要转折不能因为命中词表被删；冲突时改表达或标「需复核」。
6. **文体优先**：古风、系统文、公文腔、第一人称声口各有自己的自然写法，不把一种腔调当万能标准。

## 检查清单

- [ ] 硬禁词已逐项扫描，命中处改成了具体写法，不是同义词轮换。
- [ ] 慎用词按密度判断，没有机械清零。
- [ ] 弱化副词每千字合计不超过 3 个。
- [ ] 比喻没有成片堆叠，保留的比喻贴角色或传递信息。
- [ ] 标点停顿没有靠破折号与省略号硬造。
- [ ] 功能性身体细节没有被误删。
- [ ] 替换后没有出现新的重复模板。
- [ ] 文体特殊用法已判断，没有把系统公告改成叙述者解释。
- [ ] 拿不准的命中已标「需复核」，未混入正文。
- [ ] 词表改动没有波及剧情事实与人物关系。

## 反模式

- 把禁用词逐个换成高级同义词，读起来仍是模板。
- 为清零词表删掉伏笔、钩子或人物特征。
- 把「短」当成自然，把正常逗号长句拆成碎句串。
- 为反检测改标点、改「地/得」、故意写错字。
- 词表不分文体，一律按同一标准删。
- 只处理词，不处理句子背后的解释腔与总结腔。
- 一次命中就整段重写，改动远超问题范围。
- 把功能性身体细节当成套话删掉，导致动作结果失去依据。

## 输出约束

- 输出命中位置、分级（硬禁 / 慎用 / 看文体）、替换方向与保留理由。
- 拿不准的条目标「需复核」，不强行替换。
- 不提供脏话清单，不鼓励为「真人感」添加粗口或错字。
- 不因词表改变剧情、人设与已发生事实。
- 交付时说明实际删改与保留，不只给一份词汇对照表。
