# 人味改写

## 用途

把读起来像模型生成的段落改回具体、可读的中文，同时保留原有情节功能。
只改「怎么说」，不改「说什么」：事件、人物关系、已发生事实、信息揭露边界一律不动。
先判断一句能不能直接删，删不掉再改写；能改一个词就不重写一句。

## 硬规则

1. **先删后改**：被标记的句子先做删除测试。删掉后不丢失伏笔、钩子、人设、人物记忆、因果锚点、必要信息或转折，就直接删。丢失任意一项，只改表达方式，保留信息本体。
2. **对举句拆正面**：句内、跨句、换字、省字的「不是 A，而是 B」一律拆开，直接写 B，或让动作与结果承担对比。不得保留否定铺垫再翻转。
3. **金句收尾清零**：章末不写感悟、哲理、升华、命运总结、伏笔预告。用动作、台词、画面、未完成动作或具体后果收住。
4. **排比降级**：同一引导词或同一句型的连续三项以上，只留最有信息的一到两项，其余换说法或删除。
5. **破折号与省略号停顿改写**：正文中不靠 `——`、`—`、`--`、`……` 制造停顿，改成句号、逗号、短句、换行或动作断句。标点服务于语气，不服务于装饰。
6. **虚假抬升落回事实**：意义深远、前所未有、命运使然、时代洪流一类判断，改成具体后果、可见代价或下一步动作。
7. **套话连接词减半**：于是乎、与此同时、从而、因而、诚然、此时此刻、只见、不禁、不由自主，出现即删或改口语。转场靠事件顺序，不靠连接词提示。
8. **情绪总结删除**：他感到、他意识到、他终于明白、这一刻他懂了，删除或改成选择、台词、物件状态、实际后果。上下文已经成立的情绪，不再补一句解释。
9. **自然文本基准**：叙述以逗号长句为主，一句串 2–4 个动作或信息，逗号之间约 8–12 字，整句约 20–30 字。短句只作孤立重拍，用完回到长句。段落随情绪与动作起落，不按固定字数切。
10. **保留功能**：伤病、动作失败、人物习惯、场景特有细节、造成情节后果的身体反应可以留；只在句尾重复标注情绪的微动作删掉，不换部位、不换同义动作。
11. **替换不复用**：同一处禁用表达在相邻段落反复命中时，各给不同的具体化写法。同一个替换词反复出现，本身就是新的模板。

## 替换表

| 常见写法 | 替代方向 | 何时可以保留 |
|---|---|---|
| 眼中闪过一丝 X | 写他当场说的话、做的决定，或直接删 | 角色确实用眼神传递了对方能读到的信息 |
| 嘴角勾起一抹 X | 他笑了、他撇嘴、他别过脸 | 需要精确表情且上下文有对照 |
| 心中涌起一股 X | 写它改变了哪个选择、哪句台词、哪件东西 | 情绪推动下一步且无法用动作承载 |
| 深吸一口气 | 把话咽回去、先不接、转身去做别的事 | 角色正在为高风险动作做生理准备 |
| 仿佛 / 犹如 / 宛若 | 白描，或只留一个生活化比喻 | 比喻贴角色视角且传递新信息 |
| 不由得 / 不由自主 | 直接写动作 | 角色确实失去身体控制且有后果 |
| 只见 / 此时此刻 | 删，直接给画面 | 场内屏幕、公告等载体原文 |
| 他感到 X | 写他因此做了什么 | 低强度过场情绪，一句直写更省 |
| 声音不大，却带着 X | 写台词内容或声音特征 | 对方明确据此改变了判断 |
| 终于明白 / 从这一刻开始 | 删，落到未完成的动作或缺口 | 角色判断带偏见且改变行动 |

## 改写流程

1. **定位**：圈出候选句，按病灶分类：对举、金句、排比、破折号、抬升、套话、情绪总结。
2. **删除测试**：逐句问删掉是否损失信息、情绪、关系、代价或伏笔。无损即删。
3. **保信息改写**：有损的句子保留事实，只替换表达；把抽象判断压成角色当下能碰到的人、事、物、后果。
4. **补连接**：删完通读。若连续短句像提纲、结构虚词被扫光、每个动作都带「了一下」式尾巴，说明删过头，把非峰值叙述恢复成自然白话；不接着删。
5. **复读**：读出声音，检查段落是否卡顿、对话是否像人说话、不同角色能否分辨。
6. **登记**：拿不准是否属于功能性写法的，标注「需复核」，不强行改。

## 检查清单

- [ ] 没有句内或跨句的否定铺垫加肯定翻转。
- [ ] 章尾没有总结、感悟、升华、预告。
- [ ] 没有连续三项以上的同构排比。
- [ ] 正文停顿不依赖破折号与省略号。
- [ ] 没有无落点的情绪总结句。
- [ ] 弱化副词（缓缓、微微、轻轻、淡淡）每千字合计不超过 3 个。
- [ ] 叙述以逗号长句为主，没有通篇碎句或电报体。
- [ ] 每处删改都通过删除测试，没有整段删除剧情。
- [ ] 替换词没有在邻近段落重复成新模板。
- [ ] 拿不准的地方已标「需复核」，未混入正文。

## 反模式

- 把「去 AI 味」做成整段删除或结构重写，改动章节顺序、伏笔分布、对话占比。
- 用同义词轮换掩盖套话，例如把每个「微微」换成「稍稍」。
- 为反检测强制每句换行、把省略号改成英文点、把「地/得」全改成「的」。
- 给每个情绪词补一个身体动作，或把正常长句拆成三五字短句串。
- 机械添加口误、粗话、错别字来制造「真人感」。
- 把叙述者解释改写成另一段叙述者解释，只换了高级词汇。
- 新增原文没有的情节、设定、关系或时间线。

## 输出约束

- 输出改后文本；改动较多时按段落列出「原文 → 改后 → 一句理由」。
- 不输出 AI 百分比、评分、命中总数一类的伪精确指标。
- 不修改剧情事实、人物关系与已定设定；需要新增内容时单独申报，不混进改写结果。
- 无法判断是否该改的地方保留原文并标「需复核」，不做静默处理。
- 若原文本身成立，允许少改或只给建议，不以改动数量作为交付标准。
