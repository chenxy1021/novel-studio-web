# 对话写作

## 用途

写有信息、有潜台词、有声线差异的对话，让每一轮都在做事情：
试探、遮掩、说服、拖延、靠近、推开或保住面子。
对话不是把旁白改成引号，也不是替作者解释设定与主题。

## 硬规则

1. **口吻贴人物卡**：身份、年龄、地域、教育背景、当下压力决定用词与句长。先读人物卡再写，不靠固定口癖区分角色。
2. **每轮至少推进一项**：信息、关系、权力、选择、风险、情绪立场。整段对话结束后，局面必须与开始不同。
3. **潜台词优先**：人物想说的和说出口的可以有差。允许答非所问、说一半、用别的话挡回去；不必每句都逻辑完整。
4. **删解释性对白**：角色不会向对方复述双方都知道的背景，也不会轮流替作者讲主题。设定靠冲突与使用带出，不靠台词上课。
5. **标签低频**：普通「说」可以保留；不要每句都配「说道、问道、笑道、沉声道」。用动作、上下文或说话顺序引出说话人。
6. **动作穿插**：对话中可以插入角色正在做的事，但动作要有功能：改变距离、打断、拖延、暴露态度或造成后果。
7. **权力博弈**：对话长度与地位相关。强势方短、稳、少解释；弱势方长、急、多补充。权力反转时用句长或话轮长度突变标记。
8. **口语但不注水**：书面腔改成日常说法，成语少用；语气词、口头停顿按人物与情绪自然出现，不作为「真人感」装饰批量添加。
9. **不为比例硬扩**：不为了达到某个对话占比把心理和叙述硬改成台词。台词只在角色此刻真会说、必须说时增加。
10. **打断用动作**：犹豫、未说完、被打断，用短句、换行、动作切断或对方接话处理，不靠省略号与破折号制造停顿。
11. **多人场景限流**：一场戏只给三到四个人台词，其余降级为一个动作或一个目光。地位越高的人动作越少、越静。
12. **开场直接交锋**：对话从有张力的半句、拒绝、追问或条件开始，不从寒暄与介绍起手。需要交代关系时，用称呼、语气与说话顺序带出。
13. **一人一目标**：每轮说话前先答「他此刻想从对方身上得到什么」。答不出就不给台词。
14. **回应不必顺着来**：角色可以拒绝回答、反问、转移话题、抓住另一个词反击。真实对话不是一问一答的问卷。

## 检查清单

- [ ] 遮住名字，能分辨出每句话是谁说的吗？
- [ ] 每轮对话是否推进了信息、关系、权力或选择？
- [ ] 有没有双方都知道还重新复述一遍的背景？
- [ ] 有没有人物把自己的动机解释得太清楚？
- [ ] 对话标签是否低频，普通「说」是否被过度替换？
- [ ] 强势方与弱势方的句长、话轮是否拉开差别？
- [ ] 潜台词是否可被读者读出，而不是被台词点破？
- [ ] 有没有为了凑占比而扩写的空转台词？
- [ ] 被打断与犹豫是否用动作或短句处理，而非省略号？
- [ ] 多人场景里，没有台词的人是否只留了有功能的动作？
- [ ] 开场是否直接进入有张力的对话，而不是寒暄介绍？
- [ ] 每个说话人是否都有此刻想争取的东西？

## 反模式

- 全员同一声线：不管谁开口，用词、句长、逻辑都像同一个人。
- 说明书台词：角色向对方解释世界观、规则、关系变化，读者被迫听课。
- 信息倾倒：一个人连续说三段，只负责把细纲交代完。
- 标签刷屏：每句都用「他说道」「她笑道」，读起来像剧本格式练习。
- 情绪自述：角色直接说「我很生气」「我其实很在乎你」，把潜台词说破。
- 为占比注水：把叙述拆成无信息的一问一答，只为凑对话比例。
- 用省略号或破折号模拟停顿，读起来像断线。
- 所有人同向配合主角，没有回避、试探、拒绝或立场分歧。
- 一问一答像问卷，每句都精准回应上一句，没有抢话、误听或转移话题。
- 用寒暄、称呼与自我介绍开场，迟迟不进入冲突。

## 输出约束

- 输出对话场景正文；需要区分说话人时用动作或上下文，不靠高频标签。
- 人物设定、关系阶段、已知信息必须与上下文一致；越界亲密或突然信任需有铺垫。
- 新增关系、承诺、后续义务时单独申报，不悄悄写进对话。
- 不改变已发生事实与信息揭露边界；角色不能说出他此刻不该知道的事。
- 交付前朗读一遍：是否像人说话，是否有一句换到任何角色嘴里都成立。
