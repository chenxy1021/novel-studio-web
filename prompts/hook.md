# 章末钩子

## 用途

让章尾产生翻页动力，同时保证钩子落在本章已经发生的事实上。
钩子不是预告，也不是总结；它必须由本章的动作、信息或选择自然长出来。
章首同样需要可识别的行动、异常或未闭合期待，但不按固定字数机械卡点。

## 硬规则

1. **只写三型**：信息钩（新事实改变理解）、危险钩（紧迫威胁或倒计时）、选择钩（被迫在两个坏选项间取舍）。三型之外的花招先降级成这三类再写。
2. **事实支撑**：钩子必须能指向本章已出现的物件、台词、动作、伤势、文件、消息或人物决定。没有本章事实托底的悬念，不写。
3. **禁止旁白预告**：不写「他不知道的是」「更大的风暴即将来临」「命运已经写好」「真正的故事才刚开始」。读者只能看到角色此刻能感知的东西。
4. **禁止总结升华**：章尾不写感悟、哲理、点题、金句。用动作、台词、画面或未完成动作收住。
5. **强度匹配阶段**：开篇与高潮前要强；日常、过场、关系章可以弱钩或只留阶段目标。不要求每章都危机升级。
6. **连续两章不同型**：相邻章节不要重复同一种钩子。信息钩之后换危险钩或选择钩，避免读者疲劳。
7. **不提前用底牌**：钩子只写到期待成立为止，不把后续卷的底牌提前亮出，也不靠预告代偿本章的推进不足。
8. **章首同理**：开篇尽早出现具体人物、处境切口、异常或未闭合期待；不从天气、风景、日常流程起手，也不为了「快」把事件拆成碎句。
9. **钩子落点具体**：结尾停在一个可指认的东西上：一条未读消息、一份签了一半的文件、一句没接的话、一个正在逼近的脚步声。
10. **爽点章收口**：打脸或反转到位后，钩子可以转成新期待或旧承诺的小兑现，不必立刻再压一个危机。
11. **钩子篇幅服从信息**：只写到期待成立为止。信息复杂就多两句，信息简单就一句收住，不设固定字数配额。
12. **开场有切口**：章首尽早出现具体人物、地点、异常或未闭合动作，读者第一段就知道「谁在做什么、哪里不对劲」。
13. **回声要变义**：开头与结尾用同一意象时，结尾的含义必须已经被本章事件改写；含义没变就不必回来打卡。
14. **不靠新设定救场**：钩子不引入前文完全没有依据的新规则、新人物或新机构；需要新线索时，先在本章正文补可见的铺垫。

## 检查清单

- [ ] 钩子能指向本章的具体事实，而不是空泛威胁。
- [ ] 读者能说清「下一章我想看什么」。
- [ ] 没有旁白剧透、总结、升华或金句。
- [ ] 钩子类型标记为信息、危险或选择之一。
- [ ] 与上一章不是同一型。
- [ ] 强度与章节阶段匹配，日常章没有被强行拉满。
- [ ] 没有提前动用后续底牌。
- [ ] 章首有具体切口，没有从天气或日常流程起手。
- [ ] 结尾停在动作、画面或台词上，不是状态总结。
- [ ] 钩子没有为凑长度重复解释，落点与本章功能一致。
- [ ] 章首第一段能让读者知道谁在做什么、哪里不对劲。
- [ ] 回声意象的含义在本章已经改变，不是原样重复。
- [ ] 钩子没有依赖前文毫无铺垫的新设定或新人物。

## 反模式

- 预告式旁白：用「他不知道的是」替读者提前打开下一章。
- 空泛威胁：只写「危险正在逼近」，不说是谁、何时、以什么形式。
- 无事实反转：章尾突然抛出全新设定或人物，前文没有可指认的线索。
- 每章都危机：读者很快对高压脱敏，日常章也失去呼吸空间。
- 把总结当钩子：用「一切才刚刚开始」冒充期待。
- 为钩子牺牲本章完整性：关键冲突没演完，先跳去写下一章的诱饵。
- 用同一意象机械回声，开头结尾各贴一次，含义没有变化。
- 章首用大段背景交代代替切口，读者读完一段还不知道谁在做什么。
- 章尾靠临时新增的规则或人物制造悬念，前文没有可回查的线索。

## 输出约束

- 输出章尾段落，并标注钩子类型（信息 / 危险 / 选择）与所依托的本章事实。
- 不新增本章未发生的事实来支撑钩子；需要新线索时先在前文补可见的铺垫。
- 不写预告式旁白、不写作者旁白、不写角色无法知道的信息。
- 章首钩子与章尾钩子分别交付时，说明各自类型与强度是否匹配当前章节阶段。
- 若本章是低压或过场章，允许只给阶段目标，但要在交付说明里写明理由。
